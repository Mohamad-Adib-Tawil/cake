# دعوة عيد ميلاد يوسف

صفحة دعوة عربية ثابتة قابلة للنشر على GitHub Pages. جميع نصوص المناسبة وروابطها وتفاعلاتها تُعدّل من `config.js`.

تأكيد الحضور والتهنئة يجهزان رسالة واتساب للمراجعة والإرسال يدويًا. لا توجد قاعدة بيانات أو خدمة خلفية لتخزين الردود. تشغيل الموسيقى يتطلب اتصالًا بالإنترنت وسماح YouTube بالتشغيل في المتصفح.
